The gates

Five gates. Each one is diff-scoped, fail-closed, and tamper-aware.

A job is judged on the files it changed, never on the repository's pre-existing debt. That single rule is what keeps the fix loop convergent: an agent is only ever asked to fix something it can actually reach.

Reviewers cannot touch the code

Reviewer roles are denied Write and Edit tools at the SDK level. On top of that, every gate runs inside a snapshot-and-restore guard: if the worktree changed during the gate, the change is discarded and the gate re-runs once, then the job fails.

Prose is not filesystem authority

A gate may widen a job's file scope only through structured evidence from a deterministic check, limited to 32 paths, 8 per cycle, 24 in total. Free-text findings from a model never become permission to edit new files.

Lessons become executable

Past review and incident conclusions are written as invariant scripts under .hyqs/invariants/. They run after the suite on every job, so a lesson is learned once by a human and enforced forever by code.

Self-healing, bounded

Every retry has its own budget. None of them can be spent by another.

Merge contention never consumes a bug-fix credit. A stalled provider never consumes a timeout credit. A database deadlock never consumes anything. That separation is why the fleet converges instead of looping, and why the operator can reason about worst-case spend.

The supervisor is one elected process

A database session-level advisory lock elects exactly one supervisor across all hosts; standbys take over within 30 seconds of its death. Every 120 seconds it reclaims orphaned worker slots, checks fleet liveness, repairs dependency cycles from two provable edge classes only, classifies every failed job into one of 17 deterministic classes, and applies the matching remediation.

  • Stale branch → clean worktree, requeue with attempts reset
  • Merged but stuck → confirm on GitHub, reconcile to done
  • Deploy failed → file a fix-forward job on main; the original waits on it and closes done
  • Migration heads diverged → generate the merge revision deterministically
  • Gate finding not attributable → re-run the gate against a fresh base, suppress or file a scoped gate-fix job

AI advises the supervisor; it never drives it

An incident analyst may read a failed job's evidence and recommend one action from a closed menu: requeue at a stage, repair a bounded set of paths, file up to four chained fix jobs, or escalate. The recommendation is validated by a pure whitelist, executed only above 0.70 confidence, capped at 6 diagnoses per job, and skipped entirely when no healthy provider exists. The janitor also gives it one look before any deterministic rule dead-letters a job.

  • The job-chat explorer that lets a human ask questions about a job runs in a bubblewrap sandbox with no network, read-only tools, and a deny-by-default path guard.
  • Merge conflicts of the pure two-sided-append shape are resolved without a model at all. Anything else goes to the conflict-fix agent on the rebase budget.
